# Roadmap frontend (React + Vite)

SPA del tablero. Build:

```bash
npm run build   # desde esta carpeta, o `npm run build:roadmap` desde la raíz
```

Salida: `../../../public/roadmap/` con `base: '/roadmap/'`.

Dev (con API en :4747):

```bash
npm run dev     # http://127.0.0.1:5173/roadmap/
```

Stack: React 19, TypeScript strict, Context + useReducer, HTML5 DnD, CSS tokens del tablero original. Sin Next.js.
